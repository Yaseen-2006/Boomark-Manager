# Boomark-Manager
First HTML, CSS, JS project

🚀 Built my first Bookmark Manager using HTML, CSS & JavaScript!
I recently built a small Bookmark Manager to practice and strengthen my JavaScript fundamentals.

🔹 Features:
-Add multiple bookmarks dynamically
-Save bookmarks using Browser Local Storage
-Remove bookmarks with confirmation
-Form validation for empty fields
-Open saved bookmarks in a new tab
-Responsive and visually appealing UI

🧠 What I practiced:
-DOM Manipulation
-Event Listeners
-FormData
-JavaScript Objects & Arrays
-JSON (JSON.stringify() / JSON.parse())
-Browser LocalStorage
-Dynamic HTML generation
This project helped me understand how data can be stored in the browser and persisted even after refreshing the page.
